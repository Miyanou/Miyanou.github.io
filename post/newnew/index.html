# 秋日午后

窗外的梧桐叶落了一地，风一吹，便沙沙作响。我泡了杯热茶，坐在窗边看书，偶尔抬头看看天。

日子就这样慢下来，不急不忙。原来安静地过一个下午，也是一种难得的收获。
